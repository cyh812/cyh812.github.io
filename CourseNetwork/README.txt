总体网络力导向布局防重叠优化版（v6）

相较 v5 的主要改动：
1. 对力导向坐标做节点碰撞缓解，减少节点重叠。
2. 节点大小继续按人数映射，但压缩极大节点的视觉上限，避免单个节点覆盖周边节点。
3. 默认只显示核心标签，减少标签重叠。
4. 提供标签切换按钮：隐藏标签 / 核心标签 / 仅学科标签 / 全部标签（小字号）。
5. 悬停节点或边可查看完整名称、人数、度和边权。
6. 仍然按节点类别区分颜色和形状：培养项目=蓝色圆形，一级学科=橙色菱形，二级学科=绿色三角形。

注意：当手动切换到“全部标签（小字号）”时，由于节点数量较多，仍可能出现少量标签贴近或遮挡；默认“核心标签”版本是用于阅读和汇报的优化视图。
